# LeetCode 2011 - Final Value of Variable After Performing Operations

## Problem
Given an array of operations (`"++X"`, `"X++"`, `"--X"`, `"X--"`), determine the final value of `X` after performing all operations.

---

# My Solution

```java
class Solution {
    public int finalValueAfterOperations(String[] operations) {
        int X = 0;

        for (int i = 0; i < operations.length; i++) {
            if (operations[i].equals("X++") || operations[i].equals("++X")) {
                X++;
            } else {
                X--;
            }
        }

        return X;
    }
}
```

### Approach
- Check whether the current operation is `"X++"` or `"++X"` using `equals()`.
- If it is, increment `X`.
- Otherwise, decrement `X`.

### Time Complexity
- **O(n)**

### Space Complexity
- **O(1)**

---

# Optimized Solution

```java
class Solution {
    public int finalValueAfterOperations(String[] operations) {
        int x = 0;

        for (String operation : operations) {
            if (operation.charAt(1) == '+') {
                x++;
            } else {
                x--;
            }
        }

        return x;
    }
}
```

### Approach
Instead of comparing entire strings, this solution checks the **second character** of each operation.

The possible operations are:

| Operation | Second Character |
|-----------|------------------|
| `++X` | `+` |
| `X++` | `+` |
| `--X` | `-` |
| `X--` | `-` |

So checking only `operation.charAt(1)` is enough to determine whether to increment or decrement.

### Time Complexity
- **O(n)**

### Space Complexity
- **O(1)**

# Comparison

| My Solution | Optimized Solution |

| Uses `equals()` to compare full strings. | Checks only one character using `charAt(1)`. |
| Easy to understand for beginners. | Shorter and slightly more efficient. |
| Performs multiple string comparisons. | Performs only one character comparison. |
| Readable but a little verbose. | Cleaner and more concise. |

# What I Learned

- Sometimes the entire string doesn't need to be compared.
- Understanding the pattern in the input can simplify the solution.
- Accessing a single character (`charAt()`) is more efficient than comparing complete strings with `equals()`.
- Always look for ways to reduce unnecessary comparisons while keeping the code readable.
